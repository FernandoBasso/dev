== Intro

[NOTE]
====
Whenever possible, the vanilla vimscript _and_ the neovim, lua approach will be shown.
====

For example, add the relative path of the current buffer to the register `f`:

[source,text]
----
:let @f = expand('%')
:lua vim.fn.setreg('f', vim.fn.expand('%'))
----

We can then echo the contents of the register on the command line:

[source,text]
----
:echo @f
:= vim.fn.getreg('f')
:lua print(vim.fn.getreg('f'))
----

== Paste contents of register into a buffer

We can also paste the contents of the register into a buffer.
In INSERT mode, type kbd:[Ctrl+r] kbd:[f]. `r` stands for “register”, and `f` is the register letter we've been using for these examples so far.
