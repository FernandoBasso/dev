== Copy file path to clipboard

=== Relative path

Relative from nvim's `:pwd`, (like `pwd` or `$PWD` in the shell).

Vanilla Vim:

[source,text]
----
:let @+ = expand('%')
----

Lua:

[source,text]
----
:lua setreg('+', vim.fn.expand('%'))
----

=== Absolute (full) path

Vanilla Vim:

[source,text]
----
:let @+ = expand('%:p')
----

Lua:

[source,text]
----
:lua setreg('+', vim.fn.expand('%:p'))
----
